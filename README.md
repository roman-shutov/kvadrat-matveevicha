# Квадрат Матвеича

Статический одностраничный сайт архитектурно-декоративного бюро.

## Публикация на GitHub Pages

В настройках репозитория откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку **main** и папку **/(root)**. Нажмите **Save**.

Сайт не требует сборки: точка входа — `index.html` в корне репозитория.
